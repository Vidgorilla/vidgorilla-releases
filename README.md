# VidGorilla releases

Download files for the VidGorilla desktop app (app updates and installers). No source code lives here.

Installed copies of VidGorilla find updates through https://vidgorilla.com/updates/latest.json, which points at
the files attached to the releases in this repository. To get VidGorilla, visit https://vidgorilla.com.
